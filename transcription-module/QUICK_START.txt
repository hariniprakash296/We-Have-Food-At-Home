📋 INSTALLATION (5 minutes):

1. Navigate to module:
   cd transcription-module

2. Create virtual environment:
   python -m venv venv
   
3. Activate it:
   # macOS/Linux:
   source venv/bin/activate
   
   # Windows:
   venv\Scripts\activate

4. Install dependencies:
   pip install -r requirements.txt
   
5. Download language model:
   python -m spacy download en_core_web_sm

┌─ Option 4: Python API ─────────────────────────────────────────────┐
│                                                                    │
│   from src import TranscriptionEngine, AudioCapture              │
│                                                                    │
│   # Initialize                                                    │
│   engine = TranscriptionEngine(model_size="base")                │
│   audio = AudioCapture()                                         │
│                                                                    │
│   # Start transcription                                           │
│   engine.start()                                                 │
│   audio.start_capture(callback=engine.process_audio)            │
│                                                                    │
│   # ... record for desired duration ...                          │
│                                                                    │
│   # Stop and export                                               │
│   audio.stop_capture()                                           │
│   engine.stop()                                                  │
│   engine.export_transcript("meeting.docx", "docx")               │

⚙️ CONFIGURATION:

Edit .env file to customize:

  WHISPER_MODEL_SIZE=base     # tiny, base, small, medium, large
  USE_GPU=true                # Enable GPU acceleration
  LATENCY_TARGET=2.5          # Target latency in seconds
  ENABLE_SPEAKER_DIARIZATION=true
  ENABLE_ERROR_CORRECTION=true
  DEFAULT_EXPORT_FORMAT=docx

🆘 TROUBLESHOOTING:

Issue: "No module named 'pyaudio'"
→ Install PortAudio first, then: pip install pyaudio

Issue: Slow transcription
→ Use smaller model: WHISPER_MODEL_SIZE=tiny
→ Enable GPU: USE_GPU=true

Issue: Poor accuracy
→ Use larger model: WHISPER_MODEL_SIZE=medium
→ Enable error correction: ENABLE_ERROR_CORRECTION=true

See docs/SETUP_GUIDE.md for more troubleshooting.
